System Settings

Rate Profiles

One table for BOTH coins and vouchers: a ₱5 coin and a ₱5 voucher give the same time, data, validity and speed. Add a row for every coin your acceptor takes (a coin with no row is not counted) and every voucher price you sell. Minutes and validity are in minutes - the grey text shows them as days/hours/minutes. Speed comes from Speed Profiles below. Customers see this list (amount, time, validity) at the bottom of the login page. Vouchers already made keep their old values.

PesoMinutesData (MB, 0=unlimited) Validity (min, 0=none)Speed

Blocked Devices

Devices blocked from the Active Users tab. Enforced by a RouterOS ip-binding entry, so it holds even across a NodeMCU reboot.

Speed Profiles

Named bandwidth limits that Rate Profiles and Subscribers pick from (e.g. "Piso 2M" = 2 Mbps down / 1 up for the ₱1-₱10 coins). Used by hotspot and PPPoE alike. Saved straight to the MikroTik - new ones are created there, changed ones apply at once, even to users already connected. A speed still used by a rate or subscriber can't be removed.

NameDownload (Mbps)Upload (Mbps)

Coin Slot

Which NodeMCU pins your baseboard uses. Defaults: coin signal D5, relay D7 (the relay powers the coin acceptor only after a customer taps Insert Coin - otherwise coins are rejected). Applied as soon as you save, no restart needed.

Leave "Pesos per pulse" at 1 when the acceptor is set to 1 pulse = ₱1 (₱5 = 5 pulses, ₱10 = 10 pulses).

Branding

Changes the business name and accent color across the portal - no code editing needed. Logo changes still require editing the GUI files directly (see docs/06).

Plays sounds on the customer pages if you've added audio files to mikrotik/gui/sounds/ (exact file names below), then clicked Upload GUI Files in the desktop app: insert-coin.mp3 (voice prompt when Insert Coin opens), coin-drop.mp3 (each accepted coin), coin-music.mp3 (loops while the coin window counts down), success.mp3 (connected), error.mp3 (failed), click.mp3 (button taps), background-music.mp3 (login page music). Any missing file is simply silent.

Charging

Prices for Charging Stations (Admin > Vendos). Each coin gets its exact price's minutes; a coin with no exact price is worked out from the cheapest price, so no coin is wasted. Changes are sent to every Charging Station automatically.
